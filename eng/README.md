# Rebuild of Naruto – English subtitles (Japanese jutsu names)

This folder contains **English subtitles** for the fan edit *Rebuild of Naruto*, with **Japanese jutsu names**.

They are based on the revised English subtitles by **Maediem**:
👉 [Maediem/Rebuild-of-Naruto-Subtitles](https://github.com/Maediem/Rebuild-of-Naruto-Subtitles/)

**Maediem gave permission** to publish this edited version. Many thanks to Maediem, both for the subtitles this project is built on and for allowing these changes.

> ⚠️ **Disclaimer:** This project is **not affiliated with the *Rebuild of Naruto* fan edit itself** and is not responsible for it. It only provides subtitles for viewers of the Rebuild version.

Other languages are listed in the [repository overview](../README.md).

---

## What is different from Maediem's version?

Only the **jutsu names** have changed. Everything else (text, numbering, timing) is Maediem's.

- Jutsu are called by their **Japanese names**, like in the German translation.
- The **first time** a jutsu appears in an episode, the English name follows in parentheses:
  *Kage Bunshin no Jutsu! (Shadow Clone Jutsu)*. After that, only the Japanese name is used: *Kage Bunshin no Jutsu!*
- Nature types are Japanese too: *Katon* (Fire Style), *Suiton* (Water Style), *Fūton* (Wind Style), *Raiton* (Lightning Style), *Doton* (Earth Style) …
- Japanese names are written with long vowels (*Gōkakyū*, *Fūton*), as in the German subtitles.
- Names that are Japanese in the English version already stay as they are (*Rasengan*, *Chidori*, *Amaterasu* …).
- Where a line would get too long, it has been re-wrapped to keep it readable.

A list of all jutsu (Japanese / English / German / Dutch) is in the [`docs/`](../docs/) folder.

## *The Last* (S07E01)

Maediem's repository has no subtitles for *The Last – Naruto the Movie*. The English subtitles for S07E01 were converted from the English subtitle track of the Rebuild release (image-based VobSub → text via OCR, then corrected by hand). Signs and on-screen text are included as separate subtitles.

This file follows the release name:

> Rebuild of Naruto - S07E01 - The Last [1080p] [BluRay] [x265] [SAMPA].en.srt

## Folders and file names

Same folders and file names as Maediem's subtitles, with the suffix `.en.srt`:

> Rebuild of Naruto - S01E01 - Academy Days [1080p][4x3][AV1].en.srt

| Folder | Episodes |
|---|---|
| `Season 01 - Naruto` | S01E01 – S01E17 |
| `Season 02 - Naruto Gaiden` | S02E01 – S02E05 |
| `Season 03 - Kakashi Gaiden` | S03E01 – S03E03 |
| `Season 04 - Naruto Shippuden` | S04E01 – S04E23 |
| `Season 05 - Naruto Senjou` | S05E01 – S05E19 |
| `Season 06 - Itachi Shiden` | S06E01 |
| `Season 07 - Naruto Hiden` | S07E01 – S07E04 |
| `Season 08 - Naruto Next Generations` | S08E01 – S08E02 |

To have your player load the subtitles automatically, put the `.srt` file next to the video and give it the **same name as the video**, followed by `.en.srt`.

Prefer the English jutsu names? Use Maediem's original subtitles.
