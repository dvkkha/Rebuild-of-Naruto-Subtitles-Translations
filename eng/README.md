# Rebuild of Naruto – English subtitles (The Last)

This folder contains **English subtitles** for *The Last – Naruto the Movie* (**S07E01**) of the fan edit *Rebuild of Naruto*.

All other episodes already have English subtitles by **Maediem**, which are the basis for every translation in this repository:
👉 [Maediem/Rebuild-of-Naruto-Subtitles](https://github.com/Maediem/Rebuild-of-Naruto-Subtitles/)

Maediem's repository does not include S07E01, so this file fills that gap. It is also the source for the German and Dutch translations of this episode.

> ⚠️ **Disclaimer:** This project is **not affiliated with the *Rebuild of Naruto* fan edit itself** and is not responsible for it. It only provides subtitles for viewers of the Rebuild version.

---

## About this file

- Converted from the image-based (VobSub) English subtitle track of the Rebuild release into a text-based `.srt` file.
- The text was read with OCR and then checked and corrected by hand (letters such as I/l, apostrophes, italics).
- Signs and on-screen text (e.g. *RINNE FESTIVAL*, *HYUGA*, the chakra counter) are included as separate subtitles.
- Timing is unchanged from the original track, so it matches the **Rebuild cut** of the movie.

## Getting your player to load the subtitles

Put the `.srt` file in the same folder as the video file and give it the **same name as the video**, followed by `.en.srt`. If your video file is named differently, rename the subtitle to match.

OCR can leave small errors behind. Please report them as an **issue** or fix them with a **pull request**, mentioning the subtitle number.
